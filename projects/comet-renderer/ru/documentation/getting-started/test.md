## Блоки кода
Иногда нужно выделить код прямо в строке: `System.out.println("Hello World");`.

А иногда нужен целый блок кода. Мы пока не подключили подсветку синтаксиса, но блок уже красиво оформлен:

```java
// Пример Java кода
public class CometRenderer {
    private static boolean isInitialized = false;

    public static void init() {
        if (!isInitialized) {
            System.out.println("Инициализация рендерера...");
            isInitialized = true;
        }
    }
}
```

```bash
# Пример консольных команд
git clone https://github.com/Ferra13671/CometRenderer.git
cd CometRenderer
./gradlew build
```

## Цитаты и предупреждения
> **Примечание:** Это обычная цитата. В нее можно писать важные заметки.

> ⚠️ **Внимание!** Этот метод нельзя вызывать до инициализации рендерера, иначе приложение упадет с ошибкой.

## Таблицы
GitHub Flavored Markdown поддерживает таблицы, что очень удобно для описания методов:

| Метод | Описание | Возвращаемый тип |
| :--- | :--- | :--- |
| `init()` | Инициализирует систему | `void` |
| `draw()` | Рисует кадр | `boolean` |
| `getConfig()` | Возвращает настройки | `Config` |

## Вкладки (Tabs) — Новый синтаксис!
:::tabs
@tab Пример на Java
```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```
@tab Пример на Kotlin
```kotlin
fun main() {
    println("Hello, Kotlin!")
}
```
@tab Консоль
```bash
$ java HelloWorld

```
